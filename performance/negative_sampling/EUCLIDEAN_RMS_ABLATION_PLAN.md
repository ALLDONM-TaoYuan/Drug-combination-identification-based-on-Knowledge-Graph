# RMS 与欧几里得距离负样本采样实验方案

## 一、实验目的

比较两种距离方法筛选负样本的效果：

- 欧几里得距离（Euclidean distance）
- RMS 距离（Root Mean Square distance）

除距离计算方法外，其他条件必须保持一致。

## 二、数据划分

继续使用现有单冷启动划分：

- Train：训练药物 + 训练药物
- Val：训练药物 + 验证冷药物
- Test：训练药物 + 测试冷药物

训练集正样本只能用于计算正样本中心和阈值。验证集、测试集信息不能参与阈值计算。

## 三、正样本中心

1. 读取训练集全部正样本。
2. 为每个药物对生成与现有实验一致的特征表示。
3. 对训练正样本特征逐维求平均，得到正样本中心。

Target 仍保留每个独立靶标组合，不使用平均池化替代组合信息。

## 四、两种距离

### 1. 欧几里得距离

对样本特征向量与正样本中心计算：

```text
sqrt(各维度差值平方之和)
```

### 2. RMS 距离

对样本特征向量与正样本中心计算：

```text
sqrt(各维度差值平方的平均值)
```

RMS 和欧几里得距离的计算方式不同，因此分别计算各自的 AED，不能直接共用原始距离数值。

## 五、统一阈值规则

分别计算：

```text
AED_euclidean = 训练候选样本的欧几里得距离平均值
AED_rms       = 训练候选样本的 RMS 距离平均值
```

两种方法使用完全相同的阈值倍数：

```text
0.9 × AED
1.0 × AED
1.1 × AED
```

对应阈值为：

```text
欧几里得阈值 = n × AED_euclidean
RMS 阈值     = n × AED_rms
```

主实验采用 `1.1 × AED`；`0.9 × AED` 和 `1.0 × AED` 用于阈值敏感性分析。

## 六、负样本选择

1. 从未标记候选药物对中计算距离。
2. 保留距离大于对应阈值的候选药物对。
3. 排除所有已知正样本、自配对、重复对和跨集合冲突。
4. 从合格候选中随机抽取与正样本等量的负样本。
5. 保持正负样本比例为 `1:1`。

如果 `1.1 × AED` 下候选样本不足，必须记录并停止该组实验，不能自动降低阈值。

## 七、公平比较要求

两种方法必须使用相同的：

- 数据划分
- 训练正样本
- 候选药物对
- 特征和标准化方法
- 阈值倍数
- 随机种子：`42、52、62、72、82`
- XGBoost 参数

验证集和测试集必须使用同一份固定负样本。只有训练集负样本的筛选方法不同，避免不同方法使用不同难度的测试集。

## 八、实验分组

| 实验组 | 训练负样本规则 |
|---|---|
| Random baseline | 随机采样 |
| Euclidean-0.9 | 欧几里得距离 > `0.9 × AED` |
| Euclidean-1.0 | 欧几里得距离 > `1.0 × AED` |
| Euclidean-1.1 | 欧几里得距离 > `1.1 × AED` |
| RMS-0.9 | RMS 距离 > `0.9 × AED` |
| RMS-1.0 | RMS 距离 > `1.0 × AED` |
| RMS-1.1 | RMS 距离 > `1.1 × AED` |

每组运行五个随机种子。正式重点比较 `Euclidean-1.1` 与 `RMS-1.1`。

## 九、必须检查的内容

- 正负样本数量是否相等；
- 已知正样本冲突数是否为 0；
- 自配对和重复对是否为 0；
- Train、Val、Test 是否无交叉；
- 阈值是否只由训练候选样本计算；
- `AED`、阈值和合格候选数量是否有记录；
- Target 组合是否保留，未发生平均池化；
- 特征是否存在 NaN 或 Inf；
- 训练、验证、测试负样本是否符合固定规则。

## 十一、最终报告

每组报告以下指标的均值 ± 标准差：

- ACC（Accuracy，准确率）
- SEN（Sensitivity，敏感性/召回率）
- Specificity（特异度）
- Precision（精确率）
- F1
- ROC-AUC
- AUPR
- MCC

其中：

- `ACC = (TP + TN) / (TP + TN + FP + FN)`
- `SEN = TP / (TP + FN)`
- `Specificity = TN / (TN + FP)`
- `Precision = TP / (TP + FP)`

最终回答两个问题：

1. RMS 距离和欧几里得距离哪一种更适合筛选当前任务的负样本？
2. 阈值从 `0.9` 提高到 `1.1` 时，模型性能和候选样本数量如何变化？
